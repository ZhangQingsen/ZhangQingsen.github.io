HHL Algorithm Implementation in Qiskit

Independent technical exploration · January 2025

A step-by-step implementation of the Harrow–Hassidim–Lloyd (HHL) algorithm using Qiskit and a small numerical example. The implementation is organized around the main stages of the algorithm, from state preparation to the complete circuit.

These pages document an independent learning project and are intended as technical notes rather than a production-ready implementation.

Implementation stages

  • State Preparation

    January 15, 2025

    Preparing the input state and introducing the numerical example.

  • Quantum Phase Estimation (QPE)

    January 20, 2025

    Encoding eigenvalue information using quantum phase estimation.

  • Controlled Rotation and Ancilla Measurement

    January 25, 2025

    Applying the controlled rotation and discussing post-selection on the ancilla qubit.

  • Uncomputation (Inverse QPE)

    January 30, 2025

    Uncomputing the phase-estimation register and completing the main HHL procedure.

  • Complete HHL Implementation

    January 31, 2025

    Combining the stages into a complete implementation and examining the measurement results.
